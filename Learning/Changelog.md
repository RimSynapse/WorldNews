# Changelog

Full version history for RimSynapse - WorldNews. The mod page and Workshop description show only the latest release; every earlier version is recorded here.

## Unreleased (0.8 - in development)
- Newspaper broadsheet redesign: masthead, drop-cap lead story with illustration, side rail, an "In Brief" panel, footer, and a single linked page-scroll. Opened from the "Newspaper Published" letter's "Read newspaper" choice.
- Export to HTML: a one-click, self-contained web page (images embedded) with a selectable, copyable saved path. On-demand only - nothing is written until you click.
- Optional illustrations via pollinations.ai: off by default behind a first-run consent window; only the scene prompt is sent; pictures are cached on disk; publication holds until an image arrives, and a declined request runs that story text-only.
- Advertisements: one quirky RimWorld house ad per issue, rotating weekly from a pool of twenty - half now ship a black-and-white brand mark.
- Breaking-news telegraph: a comms-gated, movable/resizable/collapsible ticker previews events held by Core's deferred-news pipeline; without a comms console you learn of an event only when it releases and the paper reports it.
- Fixes: never publish an empty issue (needs a headline and a story with body text); a paper no longer fires the instant a colony loads.
